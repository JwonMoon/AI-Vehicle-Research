# 19. AI 에이전트(음성 에이전트 포함) 현존 기술 수준 — baseline 조사

AI 에이전트 **전반**(챗봇 수준 L0부터 장기 자율 과업 L3·다중 에이전트 L4까지)과 **음성 에이전트**의 2026년 11월 현재 기술 수준을 정량(공개 벤치마크·지연·온디바이스 비용·시장 수치)·정성(성숙도·한계)으로 파악해 기준선(baseline)을 잡는 주제. 음성 에이전트는 구성(캐스케이드 vs speech-to-speech)·블록별 오픈소스·**직접 구현 트랙**(오픈소스로 하나 조립해 자체 측정)을 포함한다. 차량 등 특정 도메인 응용은 후속편 자리로 남긴다.

## 작성 규약

- **저장소의 기존 문서를 참고·인용하지 않는다.** 외부 공개 자료(공식 리더보드·모델 카드·공식 문서·논문·언론)만 새로 수집한다.
- 모든 사실 문장에 출처 번호와 등급(🔍 공식 / 📄 논문·기술 블로그 / 📰 언론·서드파티 / 💬 포럼)을 붙인다. 벤치마크 점수는 **리더보드 조회 날짜**를 병기한다.
- 기업 자체 발표 수치는 "주장"으로 표기하고 제3자 측정·자체 측정과 구분한다. 상충 수치는 병기한다. 미확인 항목은 본문에서 빼고 "조사 방법과 한계" 장에 목록으로 남긴다.
- 계획서(`plan.md`)에 적힌 모델·벤치마크·오픈소스 이름은 조사 대상 **후보**이며, 라이선스·언어 지원·수치는 조사 단계에서 확인한다.
