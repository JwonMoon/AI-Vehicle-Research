# Jetson AGX Thor 자율주행 연구 가이드 (작성 중)

16번 주제의 후속편. Jetson AGX Thor 데브킷 기준으로 ① 사양 요약 ② 차량 관련 연구 사례와 부자재 ③ 데브킷에 카메라 붙이는 방법(Holoscan Sensor Bridge 설명 포함) ④ 참고: 차량 산업 사례(DRIVE AGX Thor 등)를 정리한다. 보고서 본문은 작성 중이며, `images/`에는 NVIDIA Holoscan Sensor Bridge 공식 문서(GitHub nvidia-holoscan/holoscan-sensor-bridge, Apache-2.0)에서 가져온 그림과 자체 작성 도식이 들어 있다.
