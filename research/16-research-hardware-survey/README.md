## 작성 규약

- **저장소의 기존 문서를 참고하지 않았다.** 외부 공개 자료(제품 페이지·README·모델카드·논문·포럼·언론)만 사용했고, 기존 보고서로의 링크·재인용이 없다.
- 모든 사실 문장에 출처 ID와 등급(🔍 공식 / 📄 논문 / 📰 언론·2차 / 💬 포럼 / ⚠️ 미확인·충돌)을 붙였다. TOPS는 정밀도를 병기하고, 가격은 조사일 공개 표시가(표시 통화 그대로)다.
- 조사 환경 제약으로 GitHub·PyPI만 직접 열람(✅)했고, 나머지는 검색 엔진 본문 발췌로 확인했다. 상세는 보고서 헤더와 출처 목록 참조.
