1. 한눈 요약

Alpamayo 2는 "같은 모델의 개선판"이 아니라 세대 교체다. 10B급 연구용 모델(1, 1.5 — 공식 명칭 "Nano")에서 34B급 robotaxi(Level 4)용 teacher 모델("Super")로 커졌고, 모델과 함께 학습 방법 자체(closed-loop RL, AlpaGym)가 바뀌었다.

2. 배경 — Alpamayo가 뭔지 3분 정리

Alpamayo = NVIDIA의 오픈 자율주행 "reasoning" 생태계. 모델 하나가 아니라 ①모델 시리즈 + ②시뮬레이터(AlpaSim) + ③RL 학습 프레임워크(AlpaGym) + ④대규모 공개 데이터셋 + ⑤auto-labeling 파이프라인 묶음. CES 2026(2026-01-05)에서 플랫폼으로 공식 발표. (🔍 CES 보도자료)

핵심 아이디어: 기존 end-to-end 자율주행 모델은 영상→궤적을 바로 뽑는다("블랙박스"). Alpamayo는 궤적을 내기 전에 "왜 그렇게 운전하는지" 텍스트로 추론 과정을 먼저 생성한다. NVIDIA는 이 추론 강제가 long-tail 상황에서 더 안전한 행동을 만들고, 안전 문서화·규제 대응에도 쓰인다고 주장. (🔍 arXiv, 📄 The Decoder)

5. Alpamayo 2에서 달라진 것 — 상세

5.1 모델: 10B Nano → 34B Super, 백본 세대 교체

  • "a 34-billion-parameter reasoning-based vision language action (VLA) model" — 이전 세대를 "Alpamayo 1 Nano / 1.5 Nano"로 명명, teacher 스케일업 설명. (🔍 보도자료 5/31)
  • 백본 Cosmos-Reason(1) → Cosmos-Reason2(1.5) → Cosmos 3 Super Reasoner 32B(2 Super). "3x the number of parameters as prior Alpamayo models". (🔍 HF 블로그 2)
  • 포지셔닝: 연구용 10B (📄 HF 런치 블로그) → "safe robotaxi (Level 4) development" + distill → DRIVE AGX Thor 탑재 구도 공식화. (🔍 보도자료)

5.2 인지: 전방 중심 → 360° 서라운드

  • 1/1.5: 전방 광각+망원, 좌우 크로스 4카메라 — 후방 없음. (🔍 R1 카드 · 1.5 카드)
  • 2 Super: "Expands from front-focused cameras to 360-degree situational awareness across front, side and rear views" — 개수 미명시("7+"는 영상 발언). (🔍 HF 블로그 2, 🎥 영상)
  • 무인 robotaxi 전제에서 후·측방 인지 필수 — Level 4 타깃과 맞물림.

5.3 출력: Meta-Action 추가

  • "Adds Meta-Action output — including macro actions such as yield, lane change and stop". (🔍 보도자료)
  • downstream planner가 소비할 상위 판단을 궤적과 병행 출력. (📄 The Decoder)
  • 참고: meta-action 개념은 R1 논문 실험에도 등장(Fig 7) — 공식 출력으로 제품화된 게 2 Super의 변화. (📄 arXiv v2)
  • 추상 3층: 텍스트 CoC(왜) → meta-action(무엇을) → 궤적(어떻게).

5.4 새 용도: Reasoning Auto-Labeling (2D grounding)

  • "reasoning auto-labeling with 2D grounding ... compressing annotation cycles from months to days". (🔍 보도자료)
  • 2 Super는 주행 모델 + 다른 모델 학습용 CoC 라벨 생성기 겸용. CoC 700K(1) → 3M(1.5) 확장도 auto-labeling 덕 (🔍 R1 카드 · 1.5 카드) — 2 Super는 라벨러를 모델 기능으로 흡수 + 근거를 이미지 내 위치(2D grounding)로 연결.
  • "수개월→수일"은 NVIDIA 주장 — 독립 검증 없음.

5.5 학습: Closed-loop RL 정식화 (AlpaGym)

  • 1의 논문 RL(GRPO)은 open-loop 중심, 1.5에서 RL post-training 공개 가중치 첫 적용. (🔍 arXiv · 1.5 카드 · GitHub)
  • AlpaGym = 시뮬레이터 in-the-loop: AlpaSim(환경) ↔ rollout ↔ Cosmos-RL(GRPO 분산 학습). (✅ GitHub alpagym · AlpaGym 블로그)
  • closed-loop 필요 이유(🎥 영상): ①covariate shift — 자기 실수 복구는 전문가 데이터에 없음 ②인과 혼동 — "빨간불이라 정지" vs "앞차가 서니 정지" 구분엔 개입(시뮬레이션) 필요.
  • 현재: 지원 모델 Alpamayo 1.5 10B뿐(2 Super 미지원), 10B 학습 GPU 2장, ≥40GB VRAM 권장, NuRec 데이터 ~1.5TB. (📄 GitHub · 블로그)
  • OmniDreams: 포토리얼 시나리오 생성 — 재구성(NuRec) → 생성형 확장 방향. (📄 GTC 뉴스 · Decoder)

8. (부록) Alpamayo 1 학습 파이프라인 요약

논문 기준: ① CoC 데이터셋 — hybrid auto-labeling + human-in-the-loop ② Stage 1 Action Modality Injection(궤적 토큰+flow matching action expert) → Stage 2 SFT(reasoning 유도) → Stage 3 GRPO 기반 RL ③ RL 효과: reasoning quality +45%, reasoning-action consistency +37%. (🔍 arXiv, 📄 arXiv v2 본문) — 그림은 §5.5.
