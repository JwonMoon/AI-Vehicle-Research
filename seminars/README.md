# 자율주행 스터디 세미나

차량용 HPC(고성능 컴퓨팅) 아키텍처 설계 팀을 위한 자율주행/고도화 ADAS 스터디 자료입니다.

## 목적

자율주행·ADAS 고도화가 차량 아키텍처의 전제가 된 상황에서, **HPC 설계 결정에 직접 참고할 수 있는 지식**을 팀 전체가 공유하는 것을 목표로 합니다. 모든 세션은 "이 내용이 우리 설계에 무엇을 요구하는가"라는 관점으로 정리되어 있습니다.

## 구성 (초기 2회차 분리판 — 요약본)

| 회차 | 제목 | 폴더 |
|------|------|------|
| 1회차 | 자율주행/ADAS 워크로드의 이해 — SW 스택이 컴퓨팅에 요구하는 것 | [`01-ad-workloads/`](01-ad-workloads/) |
| 2회차 | 차량용 HPC 플랫폼 설계 — SoC, E/E 아키텍처, 기능안전 | [`02-hpc-platform/`](02-hpc-platform/) |

### 1회차 아젠다

1. 자율주행 레벨(L2+/L3/L4)과 ADAS 고도화 트렌드 — 왜 HPC가 필수가 됐나
2. 고전적 AD 파이프라인: 센싱 → 인지 → 측위 → 판단/계획 → 제어 (모듈별 연산 특성)
3. 최신 AI 모델 트렌드: BEV+Transformer, Occupancy Network, End-to-End, VLM/VLA, World Model
4. 차량 탑재(온보드) 최적화 연구 동향: 양자화, 프루닝/희소성, 증류, 추론 최적화, 컴파일러 스택
5. 워크로드 정량화: 센서 대역폭, 추론 TOPS, 메모리 대역폭, 지연시간 예산
6. HPC 설계 시사점 정리

### 2회차 아젠다

1. 주요 AD SoC 비교: NVIDIA DRIVE Thor, Qualcomm Ride, Mobileye EyeQ, TI, Renesas, Ambarella 등
2. E/E 아키텍처 진화: 분산형 → 도메인 → 존(Zonal)/중앙집중형
3. SW 플랫폼/미들웨어: DriveOS, AUTOSAR Adaptive, ROS2, 하이퍼바이저와 혼합 중요도 분리
4. 기능안전·규제: ISO 26262, SOTIF, ISO/PAS 8800, UNECE R157/R171
5. 종합: 우리 팀 HPC 설계 체크리스트
